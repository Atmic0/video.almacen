Personal automation tool

Automated video publishing for a single TikTok account

video.almacen watches a local folder for finished video files and publishes them to one authorized TikTok account, at times the account owner schedules, using TikTok's official Content Posting API.

How it works

1

Watch a local folder

A lightweight process on the user's own device monitors a folder for newly added, ready-to-publish video files.

2

Queue and schedule

Detected videos are queued and assigned a publish time chosen by the account owner, avoiding duplicate or overlapping posting windows.

3

Publish via the official API

At the scheduled time, the video is uploaded and published to the authorized TikTok account through TikTok's Content Posting API, using the Direct Post flow.

4

Confirm and archive

The app polls the publish status until TikTok confirms the post, then moves the source file to a local archive folder.

Products & permissions used

Product Scope Purpose
Login Kit user.info.basic Authenticate the account owner via OAuth and read basic profile info (open id, avatar, display name).
Content Posting API video.publish Publish videos directly to the authorized account (Direct Post).
Content Posting API video.upload Upload video content to the authorized account.

Scope of use

Single account, individual use

The app publishes only to the one TikTok account that explicitly authorized it. No third-party accounts are managed.

No content sharing between users

Video files and captions stay on the account owner's own device before and after publishing.

User-controlled scheduling

Publish times are set by the account owner; nothing is posted outside the windows they configure.

Official API only

All publishing goes through TikTok's documented Content Posting API — no browser automation or unofficial endpoints.
